# 🌍 ExploreWorld – Travel and Tourism Website

## 📌 Project Description

ExploreWorld is a modern, responsive Travel and Tourism Website developed using **HTML5 and CSS3**. The website allows users to explore popular travel destinations, view vacation packages, browse beautiful travel images, and fill out a travel booking form.

The project focuses on creating an attractive, user-friendly interface with responsive layouts, smooth navigation, and engaging visual designs.

## 🚀 Features

- 🏠 **Home Page:** Attractive hero section with a travel-themed background image.
- 🌴 **Popular Destinations:** Displays famous destinations with images, descriptions, and sample prices.
- ✈️ **Tour Packages:** Showcases travel packages with duration, pricing, and details.
- 📸 **Travel Gallery:** Beautiful image gallery featuring travel destinations.
- 📝 **Booking Form:** Allows users to enter their name, email, destination, travel date, and number of travelers.
- 📱 **Responsive Design:** Optimized for desktop, tablet, and mobile devices.
- 🎨 **Modern UI:** Hover effects, smooth scrolling, and clean layouts.

## 🛠️ Technologies Used

- **HTML5** – Website structure and content
- **CSS3** – Styling, layouts, and responsiveness
- **CSS Flexbox** – Navigation and alignment
- **CSS Grid** – Destination cards and image gallery
- **Media Queries** – Responsive web design
- **Google Fonts** – Typography
- **Unsplash** – Travel images

## 💻 How to Run the Project

1. Clone the GitHub repository.

   ```bash
   git clone https://github.com/your-username/ExploreWorld.git
   ```

2. Open the project folder in Visual Studio Code.

3. Open `index.html`.

4. Right-click and select **Open with Live Server**, or open the HTML file directly in a browser.

5. Explore the Travel and Tourism Website!

**Note:** An internet connection is required to load the online images and Google Fonts.
